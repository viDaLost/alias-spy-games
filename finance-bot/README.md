# 💰 Finance Bot — учёт финансов в Telegram

Личный бот для подробного учёта денег. Работает на **Telegram Serverless**: без сервера, хостинга и отдельной базы данных.

## Что умеет

- **Запись текстом**: `кофе 250`, `такси 450 вчера`, `хлеб 60, молоко 90, сыр 300`, `+50000 зарплата`, `зарплата 100к`, `$20 подписка`, `12.10 продукты 3400`, `в пятницу кино 800`.
- **Голосовые** 🎙: «вчера потратил тысячу двести на продукты и триста на такси» → две записи с датой «вчера». Распознаёт Whisper, фразу разбирает LLM (Groq бесплатно или OpenAI).
- **Категория определяется автоматически**: 18 категорий расходов и 6 категорий доходов, словарь магазинов и сервисов. Если исправить категорию кнопкой, бот запомнит это слово.
- **Карточка под каждой записью**: изменить категорию, дату, сумму или описание, удалить. `/undo` отменяет последнюю запись.
- **📊 Отчёт**: расходы и доходы по категориям с долями, средний расход в день, сравнение с прошлым периодом, самые крупные траты. Листается по дням, неделям, месяцам и годам; можно задать любой период.
- **📥 Excel** за любой период:
  - *Полный отчёт*: «Сводка» (итоги и категории), «Операции» (автофильтр и итоги, которые учитывают фильтр), «По дням», «По месяцам» и **отдельная вкладка на каждую категорию**;
  - *Кратко*: сводка и список операций;
  - *Одна категория*.
- **🎯 Бюджеты**: общий и по категориям на месяц, с предупреждениями на 80% и 100%.
- **Несколько валют**, часовой пояс, свои категории (с эмодзи), приватный режим с допуском по ID.

## Структура

```
finance-bot/
├─ tgcloud/                    ← код, который выполняется на платформе
│  ├─ schema.js                  таблицы: users, categories, transactions, budgets, settings
│  ├─ handlers/message.js        входящие сообщения и голосовые
│  ├─ handlers/callback_query.js нажатия на кнопки
│  └─ lib/
│     ├─ bot.js        команды, меню, запись операций, кнопки
│     ├─ screens.js    экраны: отчёт, последние операции, Excel, категории, бюджет, настройки
│     ├─ parser.js     разбор фраз («кофе 250», числа словами, валюты)
│     ├─ dates.js      даты, периоды, часовые пояса
│     ├─ categories.js категории по умолчанию и словарь для угадывания
│     ├─ ai.js         Whisper и разбор фраз через LLM (OpenAI-совместимый API)
│     ├─ export.js     сборка Excel-отчёта
│     ├─ xlsx.js       генератор .xlsx без зависимостей (на платформе нет npm-пакетов)
│     ├─ store.js      запросы к базе
│     └─ format.js, tg.js, config.js
├─ test/                       ← локальные тесты с имитацией SDK платформы
└─ docs/tgcloud-sdk.md         справочник SDK платформы
```

## Запуск

Нужен Node.js 18 или новее.

1. В **@BotFather** включите для бота **Serverless** и скопируйте токен приложения вида `app8887807822:…` (подробнее: [core.telegram.org/bots/serverless](https://core.telegram.org/bots/serverless)).
2. В папке проекта:

   ```bash
   cd finance-bot
   npm install
   npx tgcloud login        # вставьте токен app8887807822:…
   npx tgcloud push         # загрузить код
   npx tgcloud migrate      # создать таблицы в базе
   ```

   Вместо `login` можно задать переменную окружения `TGCLOUD_TOKEN=app8887807822:…`.
3. Напишите боту `/start`. **Первый, кто напишет, становится владельцем.** Остальным бот закрыт, пока владелец не выполнит `/allow ID` (или не откроет бот для всех в ⚙️ Настройки → 👥 Доступ).
4. Подключите голосовые:
   - бесплатный ключ: [console.groq.com](https://console.groq.com) → *API Keys* → *Create API Key*;
   - отправьте боту `/setkey gsk_ваш_ключ`. Бот сразу удалит это сообщение, проверит ключ и сохранит его в базе.

   Ключ OpenAI тоже подойдёт (`/setkey sk-…`). Подойдёт и любой OpenAI-совместимый сервис: `/setkey url https://host/v1 КЛЮЧ`.

После изменений в коде: `npx tgcloud push`. После изменений в `schema.js` дополнительно выполните `npx tgcloud migrate`.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start`, `/help` | меню и подсказки |
| `/report [период]` | отчёт: `/report сентябрь`, `/report 2025` |
| `/excel [период]` | таблица: `/excel 01.09-15.09`, `/excel последние 30 дней` |
| `/last` | последние операции с кнопками правки |
| `/undo` | отменить последнюю запись |
| `/budget [категория] сумма` | `/budget 50000`, `/budget продукты 15000`, `/budget продукты 0` |
| `/categories`, `/settings` | категории и настройки |
| `/currency USD`, `/tz +5` | основная валюта и часовой пояс |
| `/id` | показать свой Telegram ID |
| **Только владелец** | |
| `/setkey`, `/setmodel stt\|llm МОДЕЛЬ`, `/ai on\|off` | распознавание речи и умный разбор |
| `/allow ID`, `/deny ID` | кому разрешено пользоваться ботом |

## Как устроен разбор

1. Текст сначала разбирают правила (`parser.js`): суммы (`1 234,50`, `5к`, «две тысячи»), валюты, даты («вчера», `12.10`, «3 сентября», «в пятницу»), несколько операций в одной фразе, доход или расход.
2. Если подключён ключ и фраза сложная (голосовое, несколько сумм, неизвестная категория), подключается LLM. Ему передаются категории пользователя, а ответ приходит строгим JSON.
3. Категория выбирается в таком порядке: слова, которым бот научился у пользователя, затем название категории, затем словарь. Если бот не уверен, он сразу предлагает выбрать категорию кнопками.

## Тесты

```bash
npm test
```

Тесты заменяют `sdk` и `sdk/db` заглушками на SQLite (`test/mock/`). По `schema.js` они создают те же таблицы, что и на платформе, и прогоняют сценарии: запись, голосовое, правки, отчёт, бюджет, выгрузку Excel. Сгенерированные таблицы сохраняются в `test/out/`.
