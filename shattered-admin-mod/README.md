# Админ-панель для Shattered Pixel Dungeon

Мод для APK `com.shatteredpixel.shatteredpixeldungeon` 4.0.0 (versionCode 912).
Панель та же, что в моде для оригинального Pixel Dungeon, но переписана под
API Shattered: другой пакет, другой движок (libGDX) и другой текстовый слой.

## Что добавляет

* **Админ-панель под паролем `1029384756`.** До ввода пароля ни одна функция не
  доступна; разблокировка живёт до перезапуска процесса игры.
* **Выдача предметов** — все 308 предметов игры в семнадцати категориях. Список
  собирается скриптом по дизассемблированному коду, так что туда попадает
  каждый предмет, который игра умеет создавать: экзотические зелья и свитки,
  эликсиры, отвары, руны, талисманы, бомбы, страницы журнала. Снаряжение идёт
  `+15`, опознанным и без проклятия; жезлы — с полным зарядом, расходники
  стопкой по 20.
* **Бессмертие** — герой не получает урона и не умирает.
* **Вечные заряды** — жезлы не разряжаются, а артефакты заправляются в момент
  включения переключателя.
* **Открытие тайных комнат** — все тайные двери и скрытые ловушки этажа
  открываются, карта раскрывается.
* **Автооткрытие панели при входе на уровень** (выключается в самой панели).
* **Сворачивание вместо закрытия** — панель уходит в ярлык «АДМ» у правого края
  и разворачивается оттуда на том же экране, где её свернули.
* **Все классы героев открыты**, включая Клирика и Дуэлянта.

## Чем отличается от мода для оригинальной игры

* Износа вещей в Shattered нет вообще — вместо этого переключателя сделаны
  вечные заряды жезлов и артефактов.
* Текст рисуется не растровым шрифтом, а `RenderedTextBlock` поверх TTF, так
  что подписи центрируются сами.
* Игра не залочена в портрет, а в ландшафте на интерфейс отводится всего 160
  точек по высоте — поэтому строки ниже, список категорий постраничный, а
  названия предметов набраны мелким кеглем.
* Классы героев открываются одной заменой `HeroClass.isUnlocked()`, а не
  правкой конкретного бейджа.

## Как всё собирается

Android SDK в сборочном окружении нет, поэтому APK не пересобирается из
исходников игры, а патчится побайтово:

1. `classes.dex` дизассемблируется baksmali;
2. `tools/gencatalog.py` собирает каталог, обходя наследников `Item`;
3. API игры превращается в компилируемые Java-заглушки (`tools/genstubs.py`),
   против которых javac собирает `src/`;
4. полученные классы переводятся в dex (dx) и вливаются в дерево smali;
5. `tools/patch.py` вносит шесть хуков в код игры;
6. `tools/verify.py` сверяет каждую ссылку нового кода с реальными членами
   классов оригинального dex;
7. smali собирает `classes.dex` обратно;
8. `tools/repack.py` пересобирает zip, сохраняя способ хранения записей и
   выравнивая несжатые записи по 4 байта;
9. `tools/SignApk.java` подписывает схемами v1 + v2 через apksig.

Ресурсы, манифест, ассеты и нативные библиотеки libGDX не трогаются.

### Хуки в коде игры

| Класс | Что делает патч |
| --- | --- |
| `actors/hero/Hero.damage()` | выходит сразу, когда включено бессмертие |
| `actors/hero/Hero.die()` | вместо смерти восстанавливает здоровье |
| `items/wands/Wand.wandUsed()` | возвращает потраченный заряд |
| `windows/WndGame.<init>()` | добавляет кнопку «АДМИН-ПАНЕЛЬ» |
| `scenes/GameScene.ready()` | вешает ярлык и разворачивает панель на новой сцене |
| `actors/hero/HeroClass.isUnlocked()` | заменён целиком на `return true` |

`GameScene.ready()` зовётся каждый ход, поэтому панель запоминает сцену, для
которой ярлык уже повешен, и повторно не срабатывает.

## Замечание про подпись

APK подписан самоподписанным ключом, поэтому поверх официальной сборки он не
встанет: её нужно удалить, а сохранения при этом пропадут.
