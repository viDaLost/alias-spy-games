# «Библейские игры» — рекламный ролик

Квадрат 1440×1440, 60 кадров/с, 14 секунд петлёй: 7 тактов по 120 BPM, 28 долей, на каждой доле — действие.
Один экран приложения всё время перестраивается в следующий: меню → «Библейские слова» → лобби «Квартета» →
партия «Квартета» → «Библейские сокровища» → «Моисей: Путь по Нилу» → иконка приложения и «Играть в Telegram» →
снова меню. Кадр 14,0 с равен кадру 0,0.

`bible-games-ad.mp4` — готовый ролик со звуком, `storyboard.jpg` — кадр каждой доли (середина доли), 7 тактов × 4.

## Что в кадре — настоящее

Ролик ничего не рисует за приложение: всё, что внутри формы-экрана, снято с работающего приложения.

| Что | Откуда |
|---|---|
| Меню | `index.html` приложения в браузере: фон сцены и лента меню во всю длину, прокрутка — жестом пальца |
| «Библейские слова» | уровень 1 (ДРАНИО): НАРОД, ИРОД, ИОНА, ДАР набраны настоящим жестом по кругу, ИОРДАН — последним, с остановкой на каждой букве; «Уровень пройден! +10⭐» и 20 → 30 звёзд — ответ игры |
| «Квартет» | лобби и партия — клиент игры, а состояние считает настоящий движок сервера (`cloudflare/quartet-worker/src/engine.js`) за подменённой сетью: комната, вход игроков, раздача, запрос карты, «Успешный запрос», кубок «Апостолы» |
| «Библейские сокровища» | экран уровня 1 «Первый свет», фишки игры, HUD; числа после хода — по формуле игры (3 × 34 = 102, каскад ×1,55 → 260) |
| «Моисей: Путь по Нилу» | запись заплыва в самой игре (3D, модели, HUD, кнопки) с управляемым временем: кнопки нажаты настоящими касаниями, прошла ли корзинка — решила игра |
| Финал | иконка приложения `web/assets/pwa/icon-512.png`, иконки игр `web/assets/icons/*`, шрифт Onest и цвета приложения |

Подготовлено для ролика, а не сыграно подряд:
- **«Сокровища».** Раскладка поля составлена из фишек игры по её правилам: одна «Библия» сдвигается, после падения
  складывается каскад. Страница проверяет, что в исходной раскладке нет готовых рядов, а после каждого падения —
  ровно один ряд. Числа HUD выставлены в самом экране игры.
- **«Моисей».** Случайные препятствия с подхода убраны, а на реку поставлены предметы самой игры: заросли папируса,
  лотосы, бревно. Они подплывают ровно к нажатиям.
- **Подписи над экраном.** Надзаголовок — название игры, крупная строка — описание с карточки меню
  («Собери слова из букв», «Собери четыре карты», «Матч-3 с Путём света», «Ведите корзинку по течению»).
  Исключение — «Играйте по сети» у лобби.
- **Оформление.** Размытый фон — сцена меню приложения. Точка-палец — указатель касания.

## Сетка долей

Доли — по измеренной сетке трека (`build/beats.json`), с единицы. ♪ — акцент в музыке.

| Такт | Доля | Сцена | Действие |
|---|---|---|---|
| 1 | 1 | меню | палец ведёт ленту меню вверх, она докатывается до «Словесных» |
| | 2 | → слова | тап по карточке «Библейские слова», карточка раскрывается в экран игры |
| | 3 | слова | буквы круга появляются шестнадцатыми |
| | 4 | слова | форма сужается к кругу букв; палец на «И» |
| 2 | 5–6 | слова | И→О→Р→Д→А→Н, строка набора растёт |
| | 7 ♪ | слова | отпускание — клетки ИОРДАНа открываются одна за другой |
| | 8 ♪ | слова | «Уровень пройден! +10⭐», ⭐ 20 → 30 |
| 3 | 9 | → лобби | форма перестраивается в лобби «Квартета», код 7QXM2A |
| | 10 | лобби | тап «Скопировать» → «Код скопирован» |
| | 11 | лобби | игроки входят: 2/15 → 3/15 → 4/15 |
| | 12 | лобби | тап «Начать игру» |
| 4 | 13 | → партия | «Партия началась», в руке «Апостолы» 3/4; форма к картам и панели хода |
| | 14 | партия | тап по Марии |
| | 15 | партия | тап по Андрею |
| | 16 ♪ | партия | тап «Спросить карту»: Андрей переворачивается, «Успешный запрос», кубок «Апостолы» |
| 5 | 17 | → сокровища | «Первый свет», фишки падают рядами |
| | 18 | сокровища | палец ведёт «Библию» вправо |
| | 19 ♪ | сокровища | обмен, три «Библии» исчезают: 102 очка, ходов 23, «Библия» 3/8 |
| | 20 ♪ | сокровища | падение, каскад ×2: 260 очков, 6/8 |
| 6 | 21 | → Нил | заплыв, «Заводь папируса» |
| | 22 ♪ | Нил | «НЫРОК» под заросли папируса |
| | 23 | Нил | «▶» — вправо, за лотосами (0 → 3) |
| | 24 ♪ | Нил | «ВОЛНА» — через бревно |
| 7 | 25 ♪ | финал | экран сворачивается в иконку, «Библейские игры» |
| | 26 | финал | «Мини-игры для компании, друзей и семьи», иконки игр шестнадцатыми |
| | 27 | финал | тап «Играть в Telegram» |
| | 28 | → меню | иконка раскрывается обратно в меню, палец на месте первого кадра |

На Ниле порядок «НЫРОК → ▶ → ВОЛНА», а не «▶ → ВОЛНА → НЫРОК», как в раскадровке. Прыжок длится 0,73 с, и нырок
на следующей доле игра не приняла бы: корзинка ещё в воздухе.

## Сборка

```sh
pip install numpy imageio-ffmpeg pillow
python3 promo/ad/make_track.py                              # музыка → build/music.wav
python3 promo/ui-motion/analyze.py promo/ad/build/music.wav # сетка долей → build/beats.json
node promo/ad/capture_app.mjs                               # экраны приложения → shots/
node promo/ad/capture_moses.mjs                             # заплыв → build/moses/ + shots/moses.js (≈ 40 мин: программный WebGL)
node promo/ad/render.mjs beats                              # кадр на долю → build/beats-sheet.png
node promo/ad/render.mjs full                               # 60 кадров/с, 4 подкадра → build/video-silent.mp4
python3 promo/ad/mix_audio.py                               # звуки интерфейса → build/final.wav
ffmpeg -i promo/ad/build/video-silent.mp4 -i promo/ad/build/final.wav -c:v copy -c:a aac -b:a 256k -shortest promo/ad/bible-games-ad.mp4
```

`render.mjs strip 5.8 6.4 0.05` — полоса кадров вокруг момента, для проверки переходов.

## Как устроено

- `index.html` — весь ролик. Любой кадр — чистая функция времени `seek(t)`: ни переходов CSS, ни таймеров.
  Открыть в браузере — внизу ползунок времени (кадры заплыва появятся после `capture_moses.mjs`); `index.html?t=5.2` — конкретный момент.
- Форма-экран — одна: её центр, размер и скругление — пружины к состояниям сцен. На главных действиях окно в экран
  сужается к нужной части и увеличивает её (круг букв, кроссворд, карты с панелью хода, поле с HUD) — это и есть
  приближение, а форма при этом остаётся под подписью. Камера добавляет лёгкие акценты и не заводит форму под подпись.
- Пружины — отклик на ступеньку в закрытом виде, значение с несколькими целями — сумма пружин с прошлым кругом,
  поэтому петля замыкается вместе со скоростью (`render.mjs` проверяет это перед рендером).
- Лента меню идёт за пальцем, пока он прижат, и докатывается пружиной, стартующей со скоростью пальца. «Библию»
  палец ведёт с сопротивлением, после отпускания она пружинит на место обмена.
- Подписи сцены: выход и вход разнесены во времени, текст не наезжает на текст.
- Кадр задан константами `FRAME` и `ZONES` — полоса подписи и область экрана; для 9:16 меняются они и
  размеры окон сцен.
- Музыка написана здесь же (`make_track.py`, фа мажор, маримба, 120 BPM) — права целиком у владельца приложения.
  Звуки интерфейса синтезированы (`mix_audio.py`) и стоят пиками на измеренных пиках ударов.
- Шрифт — Onest из приложения (`fonts/`, SIL Open Font License).

## Замечено в приложении по ходу съёмки

«Квартет» не склоняет имя и глагол: «Мария вошёл в комнату», «Вы получили карту «Андрей» у Мария». В ролик эти
строки не попали.
