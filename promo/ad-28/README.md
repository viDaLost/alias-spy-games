# «Библейские игры» — ролик 28 секунд с 3D-перетеканиями

Квадрат 1440×1440, 60 кадров/с, 28 секунд петлёй: 14 тактов по 120 BPM, 56 долей, на каждой доле — действие.
Восемь игр, и каждая вытекает из предыдущей: предмет или жест одной сцены становится началом следующей.
Кадр 28,0 с равен кадру 0,0, палец — на том же месте и с той же скоростью.

`bible-games-ad-28.mp4` — готовый ролик со звуком, `storyboard.jpg` — кадр каждой доли (середина доли), 7 рядов по 8.

Перетекания — это движение снятого, а не новые экраны: переворот формы или предмета в 3D (CSS-перспектива,
у предметов две стороны), полёт предмета из одной сцены в другую, круглое окно, в котором проявляется следующая
сцена. Частиц, свечений и новых картинок нет. Толща воды — один цвет, взятый с воды Нила из записи заплыва.

Подготовлено для ролика, а не сыграно подряд:
- **«Земля обетованная».** Какие грани выпадут, решено заранее: ровно на этот бросок игре подложены два числа
  жребия, дающие 3 и 5 (3 + 4 привели бы на «Провидение», а 3 + 5 — на «Вифлеем»). Кувырок костей и их остановка —
  самой игры.
- **«Двенадцать колен».** Раздача движка игры, но руки разложены под ролик: у каждого соперника ровно один законный ход.
- **«Художник».** Пока остальные рисуют своё, ролик переходит сразу к голосованию. Шпионом назначен Вооз.
  Линии ковчега в ролике рисуются заново по точкам, которые сохранила партия, с кистью игры (цвет и толщина из
  партии); `shots/sketch-stroke-*.webp` — как их нарисовала сама игра.
- **«Угадай персонажа».** Первому игроку выпал Моисей — он есть в списке персонажей игры.
- **«Моисей».** Как и в 14-секундной версии, предметы на реке поставлены так, чтобы подплыть к нажатиям.

## Сборка

```sh
pip install numpy imageio-ffmpeg pillow
python3 promo/ad-28/make_track.py                              # музыка → build/music.wav
python3 promo/ui-motion/analyze.py promo/ad-28/build/music.wav # сетка долей → build/beats.json
node promo/ad/capture_app.mjs                                  # экраны первых игр → promo/ad/shots/
node promo/ad-28/capture_more.mjs                              # «Двенадцать колен», «Художник», «Угадай персонажа» → shots/
node promo/ad-28/capture_moses.mjs                             # заплыв → build/moses/ + shots/moses.js (≈ 20 мин: программный WebGL)
node promo/ad-28/capture_promised.mjs                          # партия «Земли обетованной» → build/promised/ + shots/promised.js
node promo/ad-28/render.mjs beats                              # кадр на долю → build/beats-sheet.png
node promo/ad-28/render.mjs full                               # 60 кадров/с, 4 подкадра → build/video-silent.mp4
python3 promo/ad-28/mix_audio.py                               # звуки интерфейса → build/final.wav
ffmpeg -i promo/ad-28/build/video-silent.mp4 -i promo/ad-28/build/final.wav -c:v copy -c:a aac -b:a 256k -shortest promo/ad-28/bible-games-ad-28.mp4
```

`render.mjs strip 14.7 15.3 0.05` — полоса кадров вокруг момента, для проверки перетеканий.

## Как устроено

То же, что в `../ad/README.md`: любой кадр — чистая функция времени `seek(t)`, одна форма-экран, пружины в
закрытом виде, суммированные с прошлым кругом. Новое:

- **Боком.** «Земля обетованная» и «Художник» сами просят повернуть телефон — их окно 844×390, и форма перестраивается
  из стоячей в лежачую.
- **Перевороты формы.** Форма поворачивается на 180° вокруг оси; на ребре старое содержимое сменяется новым, и
  форма доворачивается к зрителю уже им.
- **Летящие предметы.** Плитка, карта, фишка, грань кубика — узел с двумя сторонами над формой. Начало и конец
  полёта берутся из того, где предмет лежит в своей сцене в этот момент (`toFrame`), поэтому он отрывается от
  экрана и ложится в следующий без скачка.
- **Круглое окно.** Следующая сцена проявляется в круге, растущем из предмета (ковчег, колодец).
- **Палец рисует.** Пока кисть на холсте, палец стоит на конце линии, а линия идёт за ним.
- Прозрачность у 3D-узла сплющивает его в плоскость, и на кадр проступила бы лицевая сторона карты, поэтому
  гаснет сторона, а не узел.

## Замечено в приложении по ходу съёмки

«Квартет» не склоняет имя и глагол: «Мария вошёл в комнату», «Вы получили карту «Андрей» у Мария». В ролик эти
строки не попали.
