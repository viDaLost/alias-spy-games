# «Одна форма» — рекламный ролик приложения

Квадрат 1440×1440, 60 кадров/с, 14 секунд петлёй: 7 тактов по 120 BPM, на каждой доле что-то происходит.
Одна и та же форма, без склеек: «Играть» → загрузка → галочка → островок комнаты → таймер раунда Alias
(▶/❚❚, перемотка) → ползунок сложности (тянется за край) → «Тёмная тема» → вкладки Слова · Шпион · Царства
→ график очков → поиск ⌘K «Цар» → Enter → уведомление → снова «Играть».

## Сборка

```sh
pip install numpy imageio-ffmpeg            # ffmpeg берётся из imageio-ffmpeg
python3 promo/ui-motion/make_track.py       # музыка: минимал-хаус 120 BPM, 7 тактов, петлёй
python3 promo/ui-motion/analyze.py          # сетка долей из самого звука → build/beats.json
node promo/ui-motion/render.mjs beats       # по кадру на долю + лист build/beats-sheet.png
node promo/ui-motion/render.mjs full        # 4 подкадра на кадр → tmix → build/video-silent.mp4
python3 promo/ui-motion/mix_audio.py        # звуки интерфейса по пикам долей → build/final.wav
# склейка:
ffmpeg -i build/video-silent.mp4 -i build/final.wav -c:v copy -c:a aac -b:a 256k -shortest one-shape.mp4
```

## Как устроено

- `index.html` — весь ролик. Любой кадр — чистая функция времени `seek(t)`: ни переходов CSS, ни таймеров.
  Открыть в браузере — внизу ползунок времени; `index.html?t=5.2` — конкретный момент.
- Пружины — формулы отклика на ступеньку (ζ ≥ 0.84, перелёт меньше процента). Значение, у которого цель
  меняется много раз, — сумма пружин по одной на смену; к ним прибавлены пружины прошлого круга, поэтому
  кадр 14,0 с совпадает с кадром 0,0 вместе со скоростью курсора (render.mjs проверяет это перед рендером).
- У ручки переключателя и индикатора вкладок края на разных пружинах: ведущий уходит вперёд, ведомый
  догоняет — отсюда «жидкое» растяжение.
- Перемотка и ползунок — прямое ведение: пока кнопка зажата, значение считается из положения курсора;
  после отпускания растяжение пружинит назад от того места, где было.
- Музыка написана здесь же (`make_track.py`) и потому свободна от прав; звуки интерфейса синтезированы
  (`mix_audio.py`) и стоят пиками на измеренных пиках ударов.
