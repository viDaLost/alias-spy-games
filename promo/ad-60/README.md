# «Библейские игры» — минутный ролик: все игры

Квадрат 1440×1440, 60 кадров/с, 62,4 секунды петлёй: 26 тактов по 100 BPM, 104 доли.
Все пятнадцать открытых игр приложения, и каждая перетекает в следующую. Кадр 62,4 с равен кадру 0,0, палец —
на том же месте и с той же скоростью. «Царства» не показаны: игра открыта пока только главному администратору.

`bible-games-ad-60.mp4` — готовый ролик со звуком, `storyboard.jpg` — кадр каждой доли (середина доли), 8 рядов по 13.

## Чем отличается от 28-секундного

- **Все игры.** К восьми играм прошлого ролика добавлены «Поиск библейских слов», «Священное слово»,
  «Соображариум», «Алиас», «Опиши, но не называй», «Соглядатай» и «Найди пару для ковчега».
- **Медленнее.** Доля 0,6 с вместо 0,5: всё, что в прошлом ролике происходило за долю, здесь идёт на пятую часть
  медленнее, в том числе записи «Моисея» и «Земли обетованной» и перевороты карточек.
- **Новая музыка.** Тёплый эмбиент-поп, ре мажор, 100 BPM: фортепиано ломаными аккордами, широкий пэд, мягкий
  щипковый бас, негромкая бочка, щелчок на 2 и 4, шейкер. На перетеканиях — колокольчик и раскрывающийся аккорд.

| «Соглядатай» | на одном телефоне, 5 игроков: у игрока 1 «Вы — соглядатай», «Передать следующему», у игрока 2 локация «Египет» |
| «Найди пару для ковчега» | «Спокойно», «У воды», поле 4×4: пара кальмаров, пара осьминогов, «Пары 2/8», «Серия из 2 пар!» |
| Финал | иконка приложения, иконки всех пятнадцати игр, шрифт Onest и цвета приложения |

Карточки «Соглядатая» и «Найди пару» игра переворачивает CSS-3D. В ролике поворот тот же: перспектива 1300 px,
кривые игры (`cubic-bezier(.18,.86,.26,1)` за 0,82 с и `cubic-bezier(.22,.74,.18,1)` за 0,44 с, растянутые на
пятую часть), стороны карточки сняты отдельно, а под поворачивающейся карточкой — экран игры без неё.

Подготовлено для ролика, а не выпало случаем (всё — из собственных списков игр):
- **«Соображариум».** Темы и буквы игра тянет случайно; здесь первый раунд — «Имя» и «Н» (НОЙ), второй — «Еда» и «М».
- **«Алиас».** Слова «Завет», «Пасха», «Агнец», «Облако» — первые из списка «Средний».
- **«Опиши».** Игроку 1 досталось слово «радуга».
- **«Соглядатай».** Роли раздаются случайно; здесь соглядатай — игрок 1, локация — «Египет».
- **«Поиск слов», «Священное слово», «Найди пару»** — ничего не подменено: первый уровень, раскладка карточек
  игры, выбраны две пары, лежащие ближе к началу поля.

## Сборка

Нужны снимки двух прошлых роликов (`promo/ad/shots`, `promo/ad-28/shots`) и записи `promo/ad-28/build/moses`,
`promo/ad-28/build/promised` — их снимают скрипты тех папок (см. их README).

```sh
pip install numpy imageio-ffmpeg pillow
python3 promo/ad-60/make_track.py                              # музыка → build/music.wav
python3 promo/ui-motion/analyze.py promo/ad-60/build/music.wav # сетка долей → build/beats.json
node promo/ad-60/capture_new.mjs                               # семь игр → shots/
node promo/ad-60/render.mjs beats                              # кадр на долю → build/beats-sheet.png
node promo/ad-60/render.mjs full                               # 60 кадров/с, 4 подкадра → build/video-silent.mp4
python3 promo/ad-60/mix_audio.py                               # звуки интерфейса → build/final.wav
ffmpeg -i promo/ad-60/build/video-silent.mp4 -i promo/ad-60/build/final.wav -c:v copy -c:a aac -b:a 256k -shortest promo/ad-60/bible-games-ad-60.mp4
```

`render.mjs strip 21.4 22.2 0.07` — полоса кадров вокруг момента, для проверки перетеканий.

## Как устроено

То же, что в `../ad-28/README.md`, плюс:

- **Шкала со вставками.** Сцены 28-секундного ролика не переписаны: их доли остались как там, а таблица `SEG`
  ставит отрезки старой шкалы на новую сетку и оставляет между ними промежутки для новых игр. Доли новых игр
  записаны через `nb(х)` и `np(х)` — «доля х новой сетки» в первом и втором промежутке. Все пружины считаются по
  времени, поэтому цели из разных отрезков складываются в одну дорожку без швов.
- **Записи игр** идут по времени старой шкалы — на пятую часть медленнее, как и всё остальное.
- **Жест по сетке.** Пока палец ведёт по АВРААМу, на экране — снимок игры с той буквой, до которой он дошёл.
- **Перевороты карточек игр** — с перспективой и кривой самих игр (см. выше).
- **Повороты формы** (`FLIPS`, `turnState`): у каждого — доля начала, вид и пружина; окна видимости сцен
  сменяются ровно на ребре. Переворот в меню кончается до стыка петли, поэтому кадр 0,0 — без поворота.
- `render.mjs beats` проверяет, что скрытые слои погашены прозрачностью, и что петля замыкается.
