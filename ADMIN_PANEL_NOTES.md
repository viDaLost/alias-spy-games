# Admin panel v2

Причина регрессии: в `index.html` перестал загружаться Telegram WebApp SDK, поэтому `getTelegramUser()` возвращал анонимного пользователя и кнопка администратора не создавалась.

Исправление:
- Telegram SDK снова подключён перед `app.js` через `defer`.
- Новый интерфейс админки вынесен в `admin-enhancements.js` и `admin-enhancements.css`.
- Админские запросы дополнительно передают `telegramInitData`, чтобы Apps Script мог валидировать Telegram-подпись на сервере.

Новый интерфейс содержит сводку пользователей, фильтры, поиск, обновление базы, копирование ID, историю игр, единое сохранение прогресса, блокировку/разблокировку и рассылку.
