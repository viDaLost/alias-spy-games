Bibelspiele auf deinem Home-Bildschirm

App-Symbol, Vollbildansicht und Spielen ohne Internet.

Diese Seite ist nicht geöffnet in Safari. Nur Safari kann das Symbol zum Home-Bildschirm hinzufügen — öffne diese Seite in Safari und kehre hierher zurück.

Vier Schritte

  1. Tippe auf «•••» — die drei Punkte unten rechts Safari.
  2. Tippe im Menü auf «Teilen“ — die Schaltfläche steht in der obersten Reihe.
  3. Scrolle nach unten und wähle «Zum „Home-Bildschirm“».
  4. Tippe auf «Hinzufügen“ — das Symbol erscheint neben deinen anderen Apps.

После установки откройте каждую игру по разу: правила и уровни сохраняются сразу, Bilder werden beim ersten Anzeigen gespeichert. Danach kannst du ohne Internet spielen.

Um Sterne und Level abzugleichen mit Telegram, melde dich nach der Installation an mit einem Code vom Bot: Öffne Profil unter Mehr.
