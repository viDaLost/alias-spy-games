# Библейская азбука

Онлайн-игра в основном приложении «Библейские игры». Код экрана находится в `web/games/bible-azbuka.*`. Приглашения открывают бота с параметром `join_azbuka_КОД`. Кнопка «Поделиться и QR» использует общее окно приглашений.

Основной API проверяет подписанные данные Telegram или сессию из приложения и допускает только главный аккаунт, заданный в `ADMIN_TELEGRAM_ID`. Сервис комнат вызывается через привязку `AZBUKA`. У него отключены публичный адрес и адреса версий. Комната закрепляет место за подтверждённым аккаунтом. Прежние комнаты используют другую схему входа и требуют создания новой комнаты.

SQLite Durable Object хранит состояние комнаты, чат и результаты. Словарь игры содержит данные Синодального перевода. Источник и контрольная сумма указаны в `synodal-dictionary.json`. Словарь включён в пакет сервиса.

Из корня репозитория проверка запускается командой `node cloudflare/bible-azbuka-online/scripts/test.mjs`. Рабочий процесс `deploy-core-cloudflare.yml` сначала публикует сервис комнат, затем основной API.
