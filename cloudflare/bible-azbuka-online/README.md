# «Библейская азбука» — онлайн-превью

Отдельная новая версия игры на категории, **не** замена существующей игры со сбором слов «Библейские слова».

- Cloudflare Worker + SQLite-backed Durable Object: комнаты по коду, доступ участника по секретному токену, ведущий, общий таймер, чат, восстановление соединения.
- Пять категорий и до трёх ответов для каждой. Система выбирает правильный вариант с минимальным числом совпадений; уникальный = 10 очков, общий = 5, неподтверждённый = 0.
- Сервер проверяет по `/synodal/game.json` первоначального превью. Ответы других игроков скрыты до завершения раунда.
- «Первый СТОП» после проверки всех категорий; таймер на 30/60/90 секунд. Пять раундов и общие итоги.
- В исходной версии «Библейских слов» ничего не меняется. Новый интерфейс доступен по `/index.html` либо `/?room=КОД`.

### Локальная сборка
```bash
node cloudflare/bible-azbuka-online/scripts/build.mjs
node cloudflare/bible-azbuka-online/scripts/test.mjs
cd cloudflare/bible-azbuka-online && npx wrangler deploy
```

Для QR используется MIT-лицензированный код, уже находящийся в репозитории: `cloudflare/full-preview/public/vendor/qrcode.min.js`.

**Ограничения:** превью использует существующий открытый словарь из предыдущего Cloudflare-превью. Для независимой эксплуатации необходимо перенести синодальные данные в этот Worker. Идентификация в комнате — по секретному токену устройства, а не через Telegram-авторизацию; привязка аккаунтов нужна перед интеграцией в основное приложение.

### Основное приложение

Основной каталог в `web/js/app.js` запускает игру `bible-azbuka` во встроенном фрейме `https://alias-spy-games-bible-azbuka.vitaledanilov.workers.dev/`. Сканер открывает камеру телефона, а во встроенном Telegram по запросу использует нативный QR-сканер приложения. Правила показываются один раз через `localStorage`.
