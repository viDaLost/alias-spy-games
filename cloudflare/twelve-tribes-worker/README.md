# Комнаты «Двенадцати колен»

Воркер держит комнаты для игры по сети: вход по коду, лобби, переписку и саму
партию. Игра при этом приходит игроку из приложения, как и все остальные, — здесь
нет ни одной страницы и ни одной картинки.

## Что внутри

| файл | что делает |
| --- | --- |
| `src/index.js` | маршруты, сессии, Durable Object комнаты, будильник стола |
| `src/room.js` | комната как данные: игроки, готовность, настройки, переписка, места |
| `src/rules.js` | правила партии — импортом из `web/games`, без единой переписанной строки |
| `src/window-shim.js` | `window` для тех же файлов, что отдаются браузеру |
| `test/room.test.mjs` | комната без воркера: `node --test test/room.test.mjs` |

Правила не продублированы нарочно. Сервер и браузер считают партию одним и тем же
кодом; разойдись они — разошлись бы не картинки на экране, а чья-то раздача.

## Что отдаётся наружу

Рука игрока не покидает сервер. `buildView` собирает отдельный вид для каждого:
своя рука целиком, у соседей — только число карт. Стол при этом повёрнут так,
что смотрящий всегда сидит на нулевом месте: экран игры написан от «вы — первый».

## Развёртывание

```sh
npm install
npx wrangler secret put SESSION_SECRET        # любой длинный случайный ключ
npx wrangler secret put TELEGRAM_BOT_TOKEN    # токен бота, которым входят игроки
npx wrangler deploy
```

После развёртывания адрес воркера прописывается в `index.html` приложения:

```html
<meta name="twelve-tribes-backend" content="https://alias-spy-games-twelve-tribes.<аккаунт>.workers.dev" />
```

Пока адрес не отвечает, игра по сети честно говорит об этом и предлагает стол за
одним столом — приложение при этом работает как обычно.

Список разрешённых источников лежит в `wrangler.jsonc` (`ALLOWED_ORIGINS`) и
должен совпадать с адресом, откуда открывают приложение.

## Приглашения

Комнату зовут теми же тремя дорогами, что и в остальных играх, и живут они не
здесь, а в приложении:

* **QR-код** — `web/js/room-invite.js`, строка вида `biblegames:tribes:КОД`;
* **друзья из избранных** — `web/js/game-friend-invites.js`, через воркер ядра;
* **ссылка** — `https://t.me/<бот>?startapp=join_tribes_КОД`.

Чтобы ссылка открывала мини-приложение, имя бота должно отдаваться воркером
ядра (`app-core-backend`) — тем же, что и для «Квартета». Отдельной настройки
для «Двенадцати колен» не нужно: игра зарегистрирована в общих списках под
коротким именем `tribes`.

## Проверки

```sh
node --test test/room.test.mjs                       # комната как данные
node scripts/check-twelve-tribes-online.mjs          # из корня репозитория: воркер + два телефона
```

Вторая поднимает настоящий воркер (`wrangler dev --local`) и настоящее
приложение, заводит два браузера и играет ими партию: создание комнаты, вход по
коду, переписку, начало партии, тайну чужой руки, отказ на чужой ход и то, что
после обрыва связи стол не замирает.
