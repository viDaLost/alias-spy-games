# Библейский художник — Cloudflare backend

Realtime backend для игры «Библейский художник».

## Источник слов

Игровой каталог `src/catalog.js` составлен по русскому **Синодальному переводу**. Для каждой игровой карточки хранится ссылка на место Писания (`ref`). В качестве открытого электронного источника для сверки используется RUSSYN на eBible.org: https://ebible.org/russyn/ — издание помечено как Public Domain.

Категории:

- `objects` — Предметы;
- `places` — Места;
- `people` — Люди;
- `events` — События / короткие формулировки из библейского текста.

Человекочитаемые варианты в `aliases` используются **только для проверки ответа шпиона** и не заменяют основное слово/фразу, показываемую художникам.

## Игровая модель

Одна комната = один SQLite-backed Durable Object `BibleSketchRoom`.

- 3–8 игроков;
- создатель комнаты выбирает категорию;
- сервер случайно выбирает шпиона, слово и порядок рисования;
- использованное слово не может повториться в этой комнате, пока не исчерпана вся выбранная категория;
- после исчерпания категории начинается новый цикл, при возможности без немедленного повтора последнего слова;
- только текущий игрок может отправлять линии на общий холст;
- шпион видит категорию, но не секретное слово;
- досрочный ответ шпиона сначала проверяет сервер;
- если автоматическое сравнение не нашло совпадение, ответ уходит на голосование остальных игроков;
- после рисования игроки голосуют за шпиона;
- если шпиона нашли, он получает финальную попытку назвать слово;
- чат комнаты хранит до 80 последних сообщений, а сервер не позволяет отправить секретное слово в чат во время активного раунда.

- `CLOUDFLARE_ACCOUNT_ID`
- `TELEGRAM_BOT_TOKEN`
- `QUARTET_SESSION_SECRET` → `SESSION_SECRET`
