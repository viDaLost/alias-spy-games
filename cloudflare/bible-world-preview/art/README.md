# Панорамы

Игра использует по одной цельной панораме на локацию. Изображения созданы
встроенным ImageGen по исходным сценам; склейка отдельных фрагментов больше не
участвует в игровом кадре. Так сохраняются широкая композиция и общий рельеф
без прямоугольных стыков между нейросетевыми фрагментами.

ImageGen вернул максимальный размер **1774 × 887** для каждой полной панорамы.
Мы сохранили этот исходный размер без увеличения и записали изображения в
lossless WebP, чтобы кодек не добавлял потерь. Экран игры использует до 3× DPR
на устройствах Retina, но это не увеличивает число деталей в самой панораме.
Встроенная генерация в этой среде не выдала исходник большего размера.

## Исходники

`sources/` хранит исходные полные PNG-панорамы, а `prompts.json` — доступные
записи запросов. Цельные изображения сгенерированы встроенным ImageGen; CLI или
внешний API для создания изображений не применялись. Полный запрос для Вавилона
из предыдущего прохода не сохранился, поэтому файл помечает этот запрос как
восстановленный для повторного запуска.

## Повторное кодирование

При наличии Pillow можно повторить без потери пикселей WebP-кодирование:

```sh
python art/package-panorama.py
```

Скрипт проверяет размеры 1774 × 887 и записывает три lossless WebP в
`public/assets`. Приложение загружает только одну текстуру на раунд. Старые
панорамы оставлены в каталоге для совместимости с кэшированными версиями.
