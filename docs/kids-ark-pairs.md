# «Найди пару для ковчега»

## Принцип игры

Главная механика не меняется: игрок открывает по две карточки, запоминает расположение животных и собирает одинаковые пары. Новые элементы поддерживают память и внимание, но не подменяют их случайными наградами или сложными правилами.

## Текущие режимы

- **Спокойно** — без таймера, для знакомства с игрой и игры в собственном темпе.
- **На скорость** — с таймером и локальными рекордами; подсказка добавляет пять штрафных секунд.
- Три размера поля: 4×4, 5×5 и 6×6.
- Три визуально-тематических набора: весь ковчег, сафари и животные у воды.

В поле 5×5 остаётся одна особая карточка-сюрприз. Она сразу считается найденной и делает нечётный размер поля понятной частью темы, а не техническим исключением.

## Обратная связь и результат

- Считаются найденные пары, ходы, точность и время скоростного режима.
- Серия правильных ответов показывает комбо, но не меняет правила и не мешает ребёнку.
- Ограниченная подсказка кратко показывает одну ненайденную пару. Использование подсказки ограничивает результат двумя звёздами.
- После победы сохраняются лучшее время, минимальное количество ходов, лучшая точность и общая статистика.

## Доступность и устойчивость

- Каждая закрытая карточка имеет уникальную подпись, а открытая сообщает название животного и состояние пары.
- Управление работает обычными кнопками с клавиатуры и сенсорного экрана.
- Модальные окна удерживают фокус и закрываются клавишей Escape там, где это безопасно.
- `prefers-reduced-motion` отключает декоративные перемещения, частицы и конфетти.
- Таймеры и отложенные действия очищаются при выходе, перезапуске и смене игры.
- Поле 6×6 отдельно проверяется на телефонах шириной 390 и 320 пикселей.

## Возможное дальнейшее развитие

1. **Короткое путешествие из нескольких полей.** Карта с тремя остановками и постепенно растущей сложностью даст ощущение приключения без изменения механики пар.
2. **Режим вдвоём на одном телефоне.** Игроки по очереди открывают карточки; найденная пара даёт ещё один ход. Это добавит семейный сценарий без отдельного backend.
3. **Иллюстрированные наборы.** Оптимизированные WebP-карточки с единым художественным стилем можно предлагать как альтернативу emoji, сохранив лёгкий базовый вариант.
4. **Опциональные звуки.** Короткие локальные эффекты переворота, совпадения и победы с явной кнопкой выключения; звук не должен запускаться до первого действия пользователя.
5. **Адаптивная рекомендация поля.** После нескольких партий предлагать следующий размер по точности и числу ходов, не меняя сложность автоматически.

Не стоит добавлять случайные усилители, обязательную валюту, рекламу между ходами или наказание за медленную игру: они отвлекают от тренировки памяти и делают детский режим тревожным.

## Проверка

```bash
npm run check:kids-pairs
npm run check:mobile
```

Первый сценарий проверяет настройки, совпадения, ошибки, подсказку, перезапуск, победу, сохранение результата и очистку состояния. Второй открывает самое плотное поле 6×6 на двух телефонных ширинах.
