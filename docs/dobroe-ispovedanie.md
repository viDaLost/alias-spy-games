# «Доброе исповедание»

Отдельное приложение для изучения вопросов и ответов «Доброго исповедания»: чтение
по вопросам, бесконечные карточки, заучивание наизусть, тесты и текст обета члена
церкви. Лежит в [`cloudflare/dobroe-worker/public`](../cloudflare/dobroe-worker/public)
и раздаётся воркером `dobroe-ispovedanie` по адресу
<https://dobroe-ispovedanie.vitaledanilov.workers.dev/>.

Своего кода на сервере нет — только статические файлы. Сборки тоже нет: файлы
правятся как есть. Прогресс хранится в браузере (`localStorage`).

| Файл | Что в нём |
| --- | --- |
| `index.html` | Разметка, теги для главного экрана iPhone |
| `styles.css` | Оформление и шрифты |
| `data.js` | Текст книги: вопросы, ответы, тексты Писания, обет, дополнения |
| `app.js` | Логика приложения |
| `sw.js` | Работа без интернета |

После правки файлов в `public/` стоит убедиться, что список в `sw.js` совпадает с
файлами на диске.

## Выкладка

Workflow [`deploy-dobroe-cloudflare.yml`](../.github/workflows/deploy-dobroe-cloudflare.yml)
выкладывает приложение при каждом изменении `cloudflare/dobroe-worker/` в `main`
(или вручную). Нужны те же секреты, что и у остальных воркеров:
`CLOUDFLARE_API_TOKEN` и `CLOUDFLARE_ACCOUNT_ID`.

## Установка на iPhone

Открыть адрес в Safari → «Поделиться» → «На экран „Домой“». Приложение откроется
без адресной строки и будет работать без интернета. Подсказка об этом показывается
на главном экране самого приложения.

## Бот в Telegram

1. В @BotFather: `/newbot`, задать имя и получить токен.
2. Сохранить токен в секрет репозитория `DOBROE_TELEGRAM_BOT_TOKEN`.
3. Запустить вручную workflow
   [`configure-dobroe-telegram.yml`](../.github/workflows/configure-dobroe-telegram.yml):
   он поставит боту кнопку «Открыть» с приложением и описание.
4. По желанию — прямая ссылка `t.me/<бот>/<имя>`: в @BotFather `/newapp`, указать
   тот же адрес.

Внутри Telegram приложение берёт его тему и показывает системную кнопку «Назад».
Хранилище у Telegram своё, поэтому прогресс там и на главном экране iPhone
отдельный.
