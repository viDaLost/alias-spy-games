# Сторонние библиотеки

## three.min.js

three.js r128 (npm-пакет `three@0.128.0`, лицензия MIT), собранный самим
проектом three.js — файл `build/three.min.js` из пакета, без изменений.

Раньше «Священное слово» подтягивало эту библиотеку с
`cdnjs.cloudflare.com`. Игра трёхмерная и без библиотеки не запускается:
`web/js/three-gate.js` ждёт её 8 секунд и, не дождавшись, показывает
«Не удалось подготовить игру». То есть единственная игра приложения зависела
от доступности и скорости чужого CDN — на медленной связи или в сети, где
cdnjs закрыт, она не открывалась вовсе.

Файл лежит рядом с приложением, поэтому:
— игра запускается везде, где открывается само приложение;
— из CSP убран `https://cdnjs.cloudflare.com` в `script-src`;
— библиотека по-прежнему грузится лениво, только при открытии этой игры,
  и не входит в вес первого экрана.

Обновление: `npm pack three@<версия>` и замена файла из `package/build/`.
