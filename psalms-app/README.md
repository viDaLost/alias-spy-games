# Псалмы — переработанное приложение сборников

Офлайн-приложение с семью сборниками духовных песен — 3633 песни:

| Сборник | Песен |
| --- | --- |
| Песни юности | 1005 |
| Мелодия юных сердец | 850 |
| Голос горлицы | 571 |
| Псалмы Сиона | 525 |
| Голосок хваления | 393 |
| Мы поём Господу | 200 |
| Кувшинчик | 89 |

Тексты взяты из базы `tools/Base_psal.db` оригинального приложения
(`com.embarcadero.Project3`, версия 1.0.45); новое приложение ставится рядом
с ним и его не трогает.

## Что внутри

| Путь | Назначение |
| --- | --- |
| `tools/Base_psal.db` | Исходная база сборников из старого APK |
| `tools/build_data.py` | Разбирает базу в JSON: заголовки, куплеты, припевы |
| `tools/icon/` | Исходник иконки и сборка её во все размеры |
| `web/` | Весь интерфейс: экраны, стили, сквозной поиск |
| `android/` | Kotlin-обёртка: WebView с ассетами, мост к системе |

`web/data/` не хранится в git — файлы собираются скриптом (Gradle делает это сам
через задачу `buildSongData`).

## Главное в интерфейсе

- **Единый поиск сразу по всем семи сборникам** — по тексту и по номеру, с подсветкой,
  ранжированием и фильтрами по сборникам; понимает латинскую раскладку
  (`dtkbrbq` → «великий») и не различает «е»/«ё».
- Экран чтения с делением на куплеты и припевы, регулировкой шрифта,
  автопрокруткой, свайпами между песнями и режимом без отвлечений.
- Псалом дня, избранное, недавние, продолжение чтения.
- Светлая и тёмная темы, плавные анимации, полностью офлайн.

## Иконка

Исходник — `tools/icon/app-icon-source.png`. После его замены достаточно
пересобрать производные размеры:

```bash
python3 psalms-app/tools/icon/build_icons.py
```

Скрипт делает обычные иконки для всех плотностей, слои адаптивной иконки
(рисунок берётся крупнее безопасной зоны, поэтому маска лаунчера срезает
только фон) и картинку для заставки приложения.

## Локальный запуск веб-части

```bash
python3 psalms-app/tools/build_data.py
python3 -m http.server 8099 --directory psalms-app/web
```

## Сборка APK

Локальный Gradle сам собирает данные и переносит `web/` в assets:

```bash
gradle -p psalms-app/android :app:assembleDebug
```

В CI это делает workflow `.github/workflows/build-psalms-apk.yml`: при наличии
секретов подписи собирается release, иначе — debug-сборка.
