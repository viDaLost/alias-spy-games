# Псалмы — переработанное приложение сборников

Офлайн-приложение с семью сборниками духовных песен — 3633 песни:

| Сборник | Песен |
| --- | --- |
| Песни юности | 1005 |
| Мелодия юных сердец | 850 |
| Голос горлицы | 571 |
| Псалмы Сиона | 525 |
| Голосок хваления | 393 |
| Мы поём Господу | 200 |
| Кувшинчик | 89 |

Тексты взяты из базы `tools/Base_psal.db` оригинального приложения
(`com.embarcadero.Project3`, версия 1.0.45); новое приложение ставится рядом
с ним и его не трогает.

## Что внутри

| Путь | Назначение |
| --- | --- |
| `tools/Base_psal.db` | Исходная база сборников из старого APK |
| `tools/build_data.py` | Разбирает базу в JSON: заголовки, куплеты, припевы |
| `tools/icon/` | Исходник иконки и сборка её во все размеры |
| `web/` | Весь интерфейс: экраны, стили, сквозной поиск |
| `android/` | Kotlin-обёртка: WebView с ассетами, мост к системе |

`web/data/` не хранится в git — файлы собираются скриптом (Gradle делает это сам
через задачу `buildSongData`).

## Интерфейс

Приложение сделано как цифровой песенник: спокойный книжный вид, минимум
украшений, весь путь «открыл → нашёл → читаю» в три касания.

- **Три раздела**: Главная, Поиск, Избранное. Настройки — иконкой в шапке главной.
- **Главная**: строка поиска, карточка «Продолжить», сетка сборников с мягкими
  цветовыми акцентами и ленты недавних и избранных песен.
- **Единый поиск сразу по всем семи сборникам** — по названию, тексту и номеру,
  с подсветкой, фильтрами по сборникам и всеми состояниями (пусто, загрузка,
  ничего не найдено, ошибка). Понимает латинскую раскладку (`dtkbrbq` → «великий»)
  и не различает «е»/«ё».
- **Экран песни** — главный экран: крупный заголовок, куплеты с номерами,
  припев с отбивкой, ширина строки ограничена 720 px, соседние песни внизу
  и свайпом, автопрокрутка для пения.
- **Управление текстом прямо в чтении**: панель внизу экрана песни меняет размер
  кнопками −/+, шрифт (системный, с засечками, без засечек) и палитру одним касанием.
  Панель уходит при прокрутке вниз и возвращается при прокрутке вверх или касании текста.
- **Панель «Аа»** в шапке — то же плюс пресеты размера и межстрочный интервал.
- **Палитры**: лаванда, олива, море, шоколад, тёмная и «как в системе». Каждая
  построена на одном тоне: фон, акценты и обложки сборников — оттенки этого цвета,
  поэтому экран не пестрит. Всё применяется сразу и сохраняется между запусками.
- Доступность: подписи у всех кнопок-иконок, область нажатия от 44 px,
  видимый фокус, уважение к `prefers-reduced-motion`.

### Палитры

Цвета тем не прописаны руками: `tools/gen_palettes.py` разводит один тон
на фон, поверхности, текст, акцент и семь ступеней для обложек сборников.
После правки параметров достаточно выполнить:

```bash
python3 psalms-app/tools/gen_palettes.py --apply
```

— и блок «Палитры» в `web/styles/app.css` перезапишется.

### Дизайн-система

`web/styles/app.css` начинается с токенов: 8-пиксельная сетка отступов,
радиусы, тени, длительности анимаций (150–250 мс), слои z-index и палитры тем.
Компоненты (`web/js/components.js`) переиспользуются всеми экранами:
`sectionHeader`, `songListItem`, `emptyState`, `skeletonList`, `segmented`,
`toggleRow`, `virtualList`.

## Иконка

Исходник — `tools/icon/app-icon-source.png`. После его замены достаточно
пересобрать производные размеры:

```bash
python3 psalms-app/tools/icon/build_icons.py
```

Скрипт делает обычные иконки для всех плотностей, слои адаптивной иконки
(рисунок берётся крупнее безопасной зоны, поэтому маска лаунчера срезает
только фон) и картинку для заставки приложения.

## Локальный запуск веб-части

```bash
python3 psalms-app/tools/build_data.py
python3 -m http.server 8099 --directory psalms-app/web
```

Сквозная проверка интерфейса (нужен Chromium и `playwright-core`):

```bash
node psalms-app/tools/check_ui.mjs
```

## Сборка APK

Локальный Gradle сам собирает данные и переносит `web/` в assets:

```bash
gradle -p psalms-app/android :app:assembleDebug
```

В CI это делает workflow `.github/workflows/build-psalms-apk.yml`: при наличии
секретов подписи собирается release, иначе — debug-сборка.
