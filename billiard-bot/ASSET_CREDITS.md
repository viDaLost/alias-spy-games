# Авторство фотографий меню

> **Статус: фотографии ещё не загружены.** В среде, где создавался проект, сетевая политика
> блокировала доступ к фотостокам (Wikimedia Commons, Unsplash, Pexels, Pixabay), поэтому
> ни одно изображение не было скачано и проверено. Фотоменю **не готово**, пока файлы ниже
> не появятся в `assets/menu/`.

Этот файл перезаписывается автоматически командой

```bash
python scripts/fetch_menu_photos.py
```

Скрипт берёт изображения только из Wikimedia Commons, по метаданным каждого файла проверяет
лицензию (принимаются CC0, Public domain, CC BY, CC BY-SA; отклоняются NC, ND и файлы с пометкой
ограничений), автора и страницу источника, оптимизирует фото под Telegram и записывает сюда
таблицу авторства с требуемой атрибуцией. Та же информация попадает в `assets/menu/credits.json`,
откуда бот показывает подпись под каждым фото и раздел «Меню кафе» → «📷 Авторы фотографий».
