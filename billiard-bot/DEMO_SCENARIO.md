# Сценарий показа заказчику (3–5 минут)

**Подготовка (заранее, 5 минут):**

1. Бот запущен (`python -m app` или `docker compose up -d`), фото меню загружены
   (`python -m app check` пишет «Фотографии меню: все на месте»).
2. Ваш Telegram ID указан в `ADMIN_IDS`, вы открыли бота и нажали /start — иначе бот не сможет
   прислать вам уведомление.
3. У заказчика — телефон с Telegram и ссылкой на бота (`t.me/<username_бота>`).
   Админ-функции заказчику не видны, пока вы явно не добавите его ID в `ADMIN_IDS`.
4. Перед показом: /admin → «🔄 Обновить демо-записи» → «Да, обновить», чтобы на ближайшие
   дни были свежие фиктивные занятые интервалы.

Ниже «Гость» — телефон заказчика, «Админ» — ваш аккаунт.

| Время | Кто | Действие | Что сказать / показать |
| --- | --- | --- | --- |
| 0:00 | Гость | Открыть бота, нажать «Запустить» | Первая строка — честное «демонстрационный бот». Пять разделов главного меню. |
| 0:20 | Гость | «🍽 Меню кафе» → «🍕 Пицца» → ▶ → «⬅️ Категории» → «☕ Напитки» | Карточка с фото, составом, весом и ценой; листание без засорения чата — карточка обновляется на месте. Внизу подписи — автор фото и лицензия. |
| 1:00 | Гость | «🏠 Главное меню» → «🎱 Забронировать стол» → «Стол № 1» → «Завтра» → «2 часа» | Цены видны сразу на кнопках длительности. В списке — только свободное время, куда влезает вся игра. Время после полуночи помечено 🌙. |
| 1:40 | Гость | Выбрать, например, 19:00 → проверить карточку → «✅ Подтвердить бронирование» | До подтверждения ничего не создаётся. Карточка: стол, начало, окончание, длительность, цена. Приходит номер брони. |
| 2:00 | Админ | Показать пришедшее уведомление «🆕 Новая бронь № …» | В уведомлении номер, стол, время и стоимость, гость — «Гость 101»; телефона и username нет. |
| 2:20 | Админ | /admin → «🎱 Расписание стола» → «Стол № 1» → «Завтра» | Занятые интервалы (бронь гостя и демо-записи), свободные окна; карточка брони по кнопке. |
| 2:50 | Админ (как второй гость) | «🏠 Главное меню» → «🎱 Забронировать стол» → «Стол № 1» → «Завтра» → «2 часа» | Время 19:00 и пересекающиеся с ним слоты в списке отсутствуют — занятое время недоступно другому гостю. Соседние интервалы (например, 21:00) доступны. |
| 3:30 | Гость | «📅 Мои бронирования» → бронь → «❌ Отменить бронь» → «Да, отменить» | Отмена с подтверждением. Админ получает «❌ Гость отменил бронь № …». |
| 4:00 | Админ | Снова «Стол № 1» → «Завтра» → «2 часа» | 19:00 снова в списке — время освободилось. |
| 4:20 | Админ | /admin → «🔒 Блокировка стола» (по желанию) | Ручная бронь «по телефону» и блокировка используют те же проверки пересечений. |

**Если что-то пошло не так:** /start всегда возвращает в главное меню; старые кнопки бот
обрабатывает безопасно («Эта кнопка устарела»). Если уведомление не пришло — проверьте, что
вы нажимали /start, и откройте /admin → «📨 Уведомления»: там видны недоставленные сообщения
и кнопка повторной отправки.

**Что подчеркнуть:** это прототип; адрес, контакты, меню и цены условные и меняются в
`config/club.json`; оплата и заказ еды не подключены; перед работой с реальными гостями нужен
список действий из README («Перед использованием с настоящими гостями»).
